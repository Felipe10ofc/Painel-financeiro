</p>📌 Sobre o projeto

O Meu Painel Financeiro é um projeto de controle financeiro pessoal desenvolvido para facilitar o gerenciamento de receitas, despesas e saldo mensal.

A aplicação tem como objetivo ajudar os usuários a organizar suas finanças de maneira simples, prática e intuitiva.

🚀 Funcionalidades

- 💵 Visualização do saldo atual.
- 📈 Registro de receitas.
- 📉 Registro de despesas.
- 🧾 Histórico de movimentações financeiras.
- 🧮 Cálculo automático do saldo.
- 📱 Interface responsiva para dispositivos móveis.

🛠️ Tecnologias utilizadas

- HTML5: estrutura da aplicação.
- CSS3: estilização e responsividade.
- JavaScript: lógica e cálculos financeiros.

🎯 Objetivos de aprendizagem

- Praticar lógica de programação.
- Desenvolver interfaces web.
- Trabalhar com manipulação do DOM.
- Aplicar conceitos de responsividade.
- Aprimorar conhecimentos em desenvolvimento Front-end.
